# 클린룸 거버넌스 (외부 하니스 패턴 재구현 시)

> mes-agent에 외부 에이전트 하니스의 **패턴**을 도입할 때 지켜야 할 출처/저작권 원칙.
> L1(에이전트 실행 루프) 강화는 이 원칙 하에 완료됨 → `docs/contracts/L1_loop_contract.md` 참고.

---

## 절대 원칙 (클린룸)

법적 출처가 불명확한 코드(유출 파생물)를 참고해야 하는 상황에서는 다음을 어기지 않는다.

1. **유출 Claude Code 소스 및 파생물(openclaude·claw-code 등)은 금지** — 읽기·참고·인용 모두 금지.
   허용 출처는 ① 이 레포 자체 코드 ② 일반 에이전트 루프 지식 ③ openclaw(MIT)·LangGraph·Temporal 등 **공개 라이선스 문서**뿐이다.
2. 레퍼런스를 부득이 참고할 경우에도 **단 한 줄도 `agent/`로 복사하지 않는다.** 설명 목적의 5줄 이하 스니펫까지만.
3. 작업은 **2단계 분리**: ① 패턴을 관찰해 *우리말 계약서*(`docs/contracts/`)만 쓰는 세션, ② 그 계약서만 보고 TDD로 구현하는 세션. 구현 세션에서는 레퍼런스를 다시 보지 않는다(진짜 클린룸).
4. 라이선스/컴플라이언스 의심 시 사내 검토를 거친다.

---

## 적용 이력

- **L1 — 에이전트 실행 루프 강화 (완료, 2026-06-10)**: G3 안전게이트 · G1 컨텍스트 compaction · G2 continuation nudge · G4 plan 모드.
  계약서 `docs/contracts/L1_loop_contract.md`(불변조건·수용기준), 구현은 `agent/server.py`·`agent/core/`·`agent/tools/_safety.py`.

> 이후 다른 서브시스템(툴 디스패치·권한 티어 등)을 같은 방식으로 도입할 경우, 위 원칙에 따라 계약서를 먼저 쓰고 TDD로 구현한다.
