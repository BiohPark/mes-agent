# 백로그 S — 대화 가독성: 의도 내레이션 + 명령 로그 축소 📖

> 상태: 🔲 미착수 · 우선순위 **상** · 근본 해결은 **백로그 U(워크플로우)** 와 함께

## 문제·가치

명령(스크립트/bash)·도구 출력이 대화창에 길게 떠 **실제 대화 흐름을 따라가기 힘들다**.
또한 에이전트가 "무엇을 할지" 먼저 말해주면 흐름 파악이 쉽다.

## 접근

### 의도 내레이션
- 각 도구 실행 **전** 한 줄 의도("브라우저로 X를 확인합니다")를 자연스럽게 노출.
- 구현: 시스템 프롬프트 지침(`agent/obsidian_session.py`) + `tool_start`의 `label` 강화(`agent/server.py`).

### 명령 로그 축소
- `tool-step`/`tool-result`(현 12px, `style.css` lines 473–500)를 **기본 접힘 + 더 작은 폰트**(스크립트/bash),
  클릭 시 펼침. 원시 명령·긴 출력은 접고 **요약만** 표시.
- 대화창은 **에이전트 텍스트 중심**으로, 도구 디테일은 보조로.

## S ↔ U 의존
근본 해결은 **상세 로그를 우측 워크플로우 패널로 이관**(U). S는 대화창을 즉시 개선하고, U가 정보가 옮겨갈 그릇.

## 핵심 파일
- `electron/renderer/chat.js`(tool_start/tool_done 렌더 lines 421–457), `style.css`(`.tool-step/.tool-result`),
  `agent/obsidian_session.py`(내레이션 지침), `agent/server.py`(label).

## 확인 필요
1. 기본 접힘 수준 — **전부 접기 vs 실패만 펼침**.
2. 내레이션을 **LLM 생성 vs 규칙 기반 라벨**.
3. 폰트 크기 기준(스크립트/bash 축소 정도).

## 규모
S~M. **우선순위 상**(즉시 효용), 근본 해결은 U와 병행.
