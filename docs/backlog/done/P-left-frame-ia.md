## 문제·가치

스레드가 늘면 사이드바가 아래로 밀려 **관리 버튼이 화면 밖으로 사라진다**(`#sidebar`에 overflow 스크롤 없음 —
`task-group-body`가 자연 흐름으로 쌓임). 빠른작업·도구테스트는 일상 가치가 낮다.

## 접근 (ASIS → TOBE)

- **ASIS**: 업무 자동화 · 빠른 작업 · 도구 테스트 · 관리
- **TOBE**: 업무 자동화 + **{추천 기능}** + 관리(**하단 고정**) + **스크롤**
- 사이드바를 3영역 flex 레이아웃: **상단 스크롤 컨테이너**(`overflow-y:auto`) + **하단 고정 푸터(관리)**.
- 빠른작업·도구테스트 제거 — 단, **도구 테스트는 접이식 '개발자 도구'로 숨김** 권장(디버깅 가치 보존, `tool-test.js`).

### 추천 신규 기능 (택 1~2)
- ⓐ **전역 검색** — 스레드/대화/워크플로우 통합 검색. 데이터가 늘수록 가치↑(가장 추천).
- ⓑ **고정/즐겨찾기 스레드** — 중요한 작업을 상단 고정.

- ⓓ **최근 활동** — 전 타입 평면 목록(빠른 재진입).
