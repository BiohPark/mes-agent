# 백로그 R — 대화 입력 에디터 개선 ⌨️

> 상태: 🔲 미착수 · 우선순위 **상**(빠른 효용·작은 규모)

## 문제·가치

긴 지시를 작성할 때 입력칸이 작아 불편하다(현재 `<textarea rows="2">`).

> **발견(재정의)**: 줄바꿈은 이미 **Shift+Enter로 동작**한다(`chat.js` keydown: `Enter && !shiftKey`→전송).
> placeholder에도 안내됨. 따라서 R의 실제 과제는 **입력 영역 크기/편집 경험**이다.

## 접근
1. **자동 높이 확장** — 내용에 따라 textarea 높이가 늘어남(최대치까지), 줄어들면 축소.
2. **확대/팝업 에디터** — 버튼으로 전체화면(또는 큰) 모달에서 긴 지시 작성.
3. **단축키 추가·안내** — 기존 Shift+Enter에 더해 **Ctrl+J / Ctrl+Enter**도 줄바꿈으로. Enter=전송 유지.
4. 붙여넣기·드래그 시 높이 적응.

## 확인 필요
1. 자동 확장 **최대 높이**.
2. **팝업 에디터** 필요 수준(자동확장만으로 충분한지).
3. Enter=전송 유지 여부(전송 키 변경 원하는지).
